# Code of conduct

We want `binspect` to be a welcoming, rigorous project. In all project spaces,
participants are expected to:

- discuss ideas and evidence without attacking people;
- give and receive technical criticism constructively;
- respect different backgrounds, identities, and levels of experience;
- avoid harassment, intimidation, discriminatory language, and unwanted attention;
- protect private or sensitive information shared during a report.

Maintainers may edit or remove contributions that violate these expectations and may
temporarily or permanently restrict participation. Report conduct concerns privately
through the repository maintainer's GitHub profile or security-advisory channel.
Reports will be reviewed promptly and handled as confidentially as practical.
