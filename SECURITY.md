# Security policy

`binspect` is a local statistical library and does not accept untrusted network
input. Security reports are still welcome, especially for dependency, build, or
artifact-integrity issues.

Please do not file a public issue for a suspected vulnerability. Use GitHub's private
security advisory feature for the repository. Include affected versions, impact, and
a minimal reproduction when possible. Until a stable release exists, only the latest
development version receives security fixes.
